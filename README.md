# Арго — сайт грузинского ресторана (Бугульма)

Next.js 16 (App Router) + TypeScript, статическая генерация. Дизайн-система «Арго» перенесена 1:1 в `components/ds` (классы `ag-*`, токены `app/styles/tokens.css`).

## Что умеет

- **Главная** — hero, категории, о ресторане, карусель хитов, акция, афиша, форма брони + Яндекс.Карта.
- **Меню `/menu`** — живой поиск, фильтры по категории и свойствам (без мяса / острое / хиты), состояние в URL (`/menu?cat=khinkali&veg=1`), липкая панель фильтров.
- **Карточка блюда** — модалка поверх любой страницы (`?dish=slug`, закрытие крестиком, Esc, кликом по фону и кнопкой «Назад», фокус заперт), на телефоне — полноэкранный лист. У каждого блюда есть своя SEO-страница `/menu/[slug]`.
- **Заказ** — корзина в `localStorage`, степперы на карточках, кнопка «Заказ» с суммой в шапке, плавающая панель на телефоне, оформление (самовывоз/доставка) → `POST /api/order`.
- **Бронь стола** — валидация имени, телефона (маска +7), даты и времени работы, согласие на ПДн (152-ФЗ) → `POST /api/booking`.
- **События `/events`** — вкладки с фильтром (`?tab=promo`), главное событие, страницы `/events/[slug]`.
- **О ресторане `/about`**, **политика** `/privacy`, `sitemap.xml`, `robots.txt`, микроразметка `Restaurant` / `Menu` / `MenuItem`, Open Graph.

## Запуск

```bash
npm install
npm run dev
```

## Заявки в Telegram

Заявки на бронь и заказы уходят администратору в Telegram, если заданы переменные окружения (в Vercel: Settings → Environment Variables):

```
TELEGRAM_BOT_TOKEN=123456:ABC...   # токен бота от @BotFather
TELEGRAM_CHAT_ID=123456789         # id чата/группы администратора
NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru
```

Без них заявки пишутся в лог функции (Vercel → Logs), а гость всё равно видит подтверждение.

## Контент

- Меню — `data/menu.json` (категории, блюда, цены, вес, метки `hit | spicy | veg | new | chef | sale`; необязательные `details`, `composition`, `allergens`, `cookTime`, `nutrition`, `image`).
- Афиша — `data/events.json`.
- Адрес, телефон, часы, координаты, соцсети — `lib/site.ts`.

Всё в `[квадратных скобках]` — заглушки из макета, заменить до запуска. Фото: положить в `public/` и указать путь в поле `image`, до тех пор показывается `PhotoSlot` с подписью, что снимать.
